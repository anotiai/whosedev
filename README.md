# WhoseDev public issue tracker

Use this repository to report reproducible WhoseDev bugs and request product improvements.

WhoseDev is proprietary software. Its source code is intentionally not published here.

Before opening an issue, review the [troubleshooting guide](https://docs.whosedev.com/troubleshooting). Do not include passwords, API keys, access tokens, private code, or personally identifiable information in an issue, log, or attachment.

For a problem with an extension, please report it to the extension's own repository when possible.
